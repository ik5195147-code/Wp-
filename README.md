# 🤖 WA Bot Host — WhatsApp বট হোস্টিং ড্যাশবোর্ড

GitHub-এ আপলোড করে **Railway**-তে ডিপ্লয় করার মতো একটি Node.js প্রজেক্ট। এটি আপনার `GroupGuard` WhatsApp বটকে সার্ভারে ২৪ ঘণ্টা চালায় এবং একটি **ওয়েব ড্যাশবোর্ড** দেয়, যেখান থেকে ব্রাউজারে বসেই:

- বট স্টার্ট / স্টপ / রিস্টার্ট করা যায়
- **পেয়ারিং কোড বা QR** দিয়ে WhatsApp লিংক করা যায় (সার্ভারে টার্মিনাল নেই, তাই এটি জরুরি)
- WhatsApp লগআউট (সেশন মুছে নতুন নম্বর লিংক) করা যায়
- লাইভ লগ ও অবস্থা দেখা যায়

## আর্কিটেকচার

```
ব্রাউজার ──HTTPS──► Railway ► server.js (Express, পাসওয়ার্ড-সুরক্ষিত)
                                  │
                                  ▼
                           src/botManager.js ──► Baileys ──► WhatsApp
                                  │
                                  ▼
                        /data (Railway Volume): auth/ (সেশন) + db.json (গ্রুপ সেটিংস, লগ, স্ট্যাটস)
```

```
wa-bot-host/
├── server.js            # ওয়েব সার্ভার, লগইন, API, হেলথচেক, গ্রেসফুল শাটডাউন
├── src/
│   ├── botManager.js    # বটের লাইফসাইকেল, QR, পেয়ারিং কোড, অটো-রিকানেক্ট
│   └── logBuffer.js     # লাইভ লগ বাফার
├── public/index.html    # ড্যাশবোর্ড (মোবাইল-ফ্রেন্ডলি, বাংলা)
├── bot/                 # আগের GroupGuard বটের কোড (features, lib, config)
├── Dockerfile           # Railway বিল্ড (git সহ, Baileys এর জন্য দরকার)
├── railway.json         # হেলথচেক ও রিস্টার্ট নীতি
└── .env.example         # সব ভেরিয়েবলের তালিকা
```

**রিপোজিটরি প্রাইভেট রাখুন।** `.env`, `auth/`, `data/` আগে থেকেই `.gitignore`-এ আছে, তবু সিক্রেট কখনো কোডে লিখবেন না।

```bash
# জিপ থেকে খুলুন (ডাউনলোড ফোল্ডারে থাকলে)

cd wa-bot-host

pkg install git -y
git config --global user.name "আপনার নাম"
git config --global user.email "you@example.com"

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/ইউজারনেম/রিপো-নাম.git
git push -u origin main
```

- আগে github.com-এ **New repository** (Private) বানান; নাম ওপরের `রিপো-নাম`-এ বসান।
- পুশের সময় পাসওয়ার্ড চাইলে **Personal Access Token** দিন (GitHub → Settings → Developer settings → Personal access tokens → `repo` অনুমতি)। অ্যাকাউন্ট পাসওয়ার্ড কাজ করে না।

## ধাপ ২: Railway-তে ডিপ্লয়

১. [railway.com](https://railway.com) এ GitHub দিয়ে লগইন করুন।
২. **New Project → Deploy from GitHub repo** → আপনার রিপো বেছে নিন। `Dockerfile` দেখে Railway নিজেই বিল্ড করবে।
৩. সার্ভিসের **Variables** ট্যাবে এগুলো দিন (বিস্তারিত নিচের টেবিলে):
   - `ADMIN_PASSWORD` — **আবশ্যক**, শক্ত পাসওয়ার্ড (≥ ৮ অক্ষর)
   - `OWNER_NUMBERS` — আপনার নম্বর (যেমন `8801XXXXXXXXX`)
   - `DATA_DIR` = `/data`
   - চাইলে `YOUTUBE_API_KEY`, `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET` ইত্যাদি
৪. **Volume যোগ করুন (খুব গুরুত্বপূর্ণ):** সার্ভিসে একটি Volume অ্যাটাচ করে **Mount path** দিন `/data`। (নির্দেশিকা: docs.railway.com/reference/volumes)
   > Volume ছাড়া Railway-র ফাইল সিস্টেম অস্থায়ী — প্রতিবার ডিপ্লয়/রিস্টার্টে WhatsApp সেশন ও গ্রুপ সেটিংস মুছে যাবে এবং আবার QR স্ক্যান করতে হবে। ড্যাশবোর্ডে Volume শনাক্ত না হলে হলুদ সতর্কবার্তা দেখাবে।
৫. **Settings → Networking → Generate Domain** চাপুন, একটি `https://….up.railway.app` লিঙ্ক পাবেন।
৬. ডিপ্লয় শেষ হলে (লগে "ড্যাশবোর্ড চালু" দেখা যাবে) লিঙ্কটি খুলুন।

### প্রথমবার WhatsApp লিংক

১. ড্যাশবোর্ডে `ADMIN_PASSWORD` দিয়ে লগইন করুন।
২. বট অটো-স্টার্ট হলে অবস্থা **"লগইনের অপেক্ষায়"** দেখাবে। (না হলে **স্টার্ট** চাপুন।)
৩. **পেয়ারিং কোড (ফোনের জন্য সহজ):** বটের নম্বর কান্ট্রি কোড সহ লিখে **কোড নিন** → ৮ অক্ষরের কোড আসবে → বটের নম্বরের WhatsApp-এ *Settings → Linked devices → Link a device → "Link with phone number instead"* তে কোডটি বসান।
   অথবা **QR:** অন্য ডিভাইসে ড্যাশবোর্ড খুলে QR স্ক্যান করুন।
৪. অবস্থা **✅ সংযুক্ত** হলে বটকে গ্রুপে যোগ করে **অ্যাডমিন** বানান এবং `.help` লিখুন।

## বটের ভাষা ও ডিজাইন

গ্রুপে বটের সব মেসেজ ও কমান্ডের উত্তর এখন **ইংরেজিতে**। শুধু এই ড্যাশবোর্ড ও README বাংলায়। গ্রুপের নোটিশ (ওয়েলকাম, ওয়ার্ন ইত্যাদি) চাইলে `.lang bn` দিয়ে বাংলাও করা যায়।

### থিম, ফন্ট ও ওয়েলকাম-কার্ড

| কমান্ড (অ্যাডমিন) | কাজ |
|---|---|
| `.theme` / `.theme galaxy` | থিম তালিকা / বদলানো: `blossom` `classic` `royal` `neon` `galaxy` `cyber` `candy` `minimal` |
| `.font` / `.font script` | ফন্ট তালিকা (নমুনা সহ) / বদলানো। `auto` = প্রতিটি থিমের নিজস্ব ফন্ট-মিশ্রণ (ডিফল্ট) |
| `.lang en` / `.lang bn` | গ্রুপ-নোটিশের ভাষা |
| `.welcomestyle card\|photo\|text` | `card` = মেসেজের সাইডে সদস্যের প্রোফাইল ছবি সহ কার্ড (ডিফল্ট), `photo` = বড় ছবি + ক্যাপশন, `text` = শুধু টেক্সট |
| `.preview welcome\|goodbye\|tagall\|mute\|rank\|warn\|levelup` | বর্তমান ডিজাইনের প্রিভিউ |
| `.setwelcome <টেক্সট>` / `.setgoodbye` | নিজের টেক্সট (`{user}` `{group}` `{count}`); `reset` = ডিফল্ট |

ফন্ট: `bold` `serifbold` `italic` `bolditalic` `sansitalic` `script` `fraktur` `boldfraktur` `double` `mono` `smallcaps` `wide` `circle` `square`।

- WhatsApp টেক্সটে সত্যিকারের রঙ বা গ্রেডিয়েন্ট দেয় না। তাই রঙের অনুভূতি আনা হয়েছে থিম-অনুযায়ী ইমোজি আর ফ্রেম দিয়ে (🌸 Blossom, 🍬 Candy, 🌌 Galaxy ইত্যাদি)।
- ফন্ট শুধু ইংরেজি অক্ষর বদলায়। বাংলা, ইমোজি ও `@মেনশন` একই থাকে। খুব পুরনো ফোনে বক্স (▯) দেখাতে পারে এবং সার্চে ধরা পড়ে না।
- `card` স্টাইলটি WhatsApp-এর অনানুষ্ঠানিক "লিঙ্ক-প্রিভিউ কার্ড" কৌশল ব্যবহার করে। কোনো ভার্সনে কার্ড না দেখালেও টেক্সটটি ঠিকই যায়; তখন `.welcomestyle photo` ব্যবহার করুন।
- নতুন থিম বানাতে `bot/lib/render.js`-এর `THEMES`-এ একটি এন্ট্রি যোগ করুন। লেখা বদলাতে `bot/lib/i18n.js`।

### `.help` থেকে ফিচার চালু/বন্ধ (অ্যাডমিন)

`.help` লিখলে নম্বর দেওয়া ফিচার-প্যানেল (✅/❌) আসে:

```
.help 1 on            # নম্বর দিয়ে
.help antilink off    # নাম দিয়ে
.help all off         # ১১টি ফিচার একসাথে বন্ধ (Welcome, Goodbye সহ)
```

| # | ফিচার | কী করে |
|---|---|---|
| 1 | Anti-Link | লিঙ্ক ডিলিট + সেন্ডার রিমুভ |
| 2 | Anti-Sticker | সদস্যের স্টিকার ডিলিট |
| 3 | Anti-Mention | মাস-মেনশন ডিলিট |
| 4 | Anti-Flood | অল্প সময়ে অনেক মেসেজ দিলে ডিলিট + ওয়ার্ন |
| 5 | Word Filter | নিষিদ্ধ শব্দ ডিলিট + ওয়ার্ন |
| 6 | Delete Log | কেউ মেসেজ মুছলে অ্যাডমিন-লগে রাখে (গ্রুপে আবার পাঠায় না) |
| 7 | Welcome | নতুন সদস্যের জন্য ওয়েলকাম |
| 8 | Goodbye | কেউ গ্রুপ ছাড়লে বিদায়-বার্তা |
| 9 | Admin Alerts | প্রোমোট/ডিমোট/রিমুভের ঘোষণা |
| 10 | Level-Up Alerts | কেউ লেভেল পেলে ঘোষণা |
| 11 | Verification | নতুন সদস্যকে যোগফল সমাধান করতে হয়, না পারলে রিমুভ |

নতুন গ্রুপে সুরক্ষা-ফিচারগুলো (১–৬, ১০, ১১) ডিফল্টে **বন্ধ**; Welcome, Goodbye ও Admin Alerts চালু। সাধারণ সদস্য শুধু প্যানেল দেখতে পারেন।

### নতুন ফিচার ও কমান্ড

| কমান্ড | কে | কাজ |
|---|---|---|
| `.warn @user [কারণ]`, `.resetwarn @user` | অ্যাডমিন | ওয়ার্ন দেওয়া/মোছা। `WARN_LIMIT` (ডিফল্ট ৩) পূর্ণ হলে অটো-কিক। রিপ্লাই করেও কাজ করে |
| `.warns` | সবাই | নিজের ওয়ার্ন দেখা (অ্যাডমিন অন্যেরটাও দেখতে পারেন) |
| `.addword`, `.delword`, `.words` | অ্যাডমিন | নিষিদ্ধ শব্দের তালিকা (বাংলাও চলে)। চালু করতে `.help wordfilter on` |
| `.autoclose 23:00 06:00` / `off` | অ্যাডমিন | প্রতিদিন নির্দিষ্ট সময়ে গ্রুপ বন্ধ ও খোলা (`TIMEZONE` অনুযায়ী) |
| `.kick`, `.promote`, `.demote` | অ্যাডমিন | মেনশন বা রিপ্লাই করে (বটকে অ্যাডমিন হতে হবে) |
| `.hidetag <টেক্সট>` | অ্যাডমিন | সবাইকে নোটিফিকেশন, তালিকা না দেখিয়ে |
| `.link` | অ্যাডমিন | গ্রুপের ইনভাইট লিঙ্ক |
| `.rank [@user]` | সবাই | লেভেল কার্ড (XP বার সহ) |
| `.leaderboard` | সবাই | XP র‍্যাঙ্কিং |
| `.top [n]` | সবাই | মেসেজ সংখ্যায় সেরা সদস্য (২০ জন পর্যন্ত) |
| `.highlights` | সবাই | জনপ্রিয় মেসেজ |
| `.info`, `.rules`, `.ping` | সবাই | গ্রুপ তথ্য, নিয়ম, বট অনলাইন কি না |
| `.verify <উত্তর>` | নতুন সদস্য | ভেরিফিকেশন |
| `.mute [নোট]` (`.close`), `.unmute` (`.open`) | অ্যাডমিন | গ্রুপ বন্ধ/খোলা |

- **XP:** প্রতি সাধারণ মেসেজে ৫–১০ XP, একই জন `XP_COOLDOWN` সেকেন্ডে একবারের বেশি পায় না (স্প্যাম করে লেভেল বাড়ানো যায় না)। লেভেল n পেতে 100 × n² XP।
- **ফ্লাড/ব্যাড-ওয়ার্ড:** মেসেজ ডিলিট করতে বটকে গ্রুপের অ্যাডমিন হতে হবে। অ্যাডমিন ও বটের নম্বর এসব নিয়ম থেকে মুক্ত।
- **ব্যান ঝুঁকি:** অটো-কিক, অটো-মিউট ও ভেরিফিকেশন-রিমুভ অনানুষ্ঠানিক বটের জন্য বাড়তি ঝুঁকি। সুরক্ষা-ফিচারগুলো তাই ডিফল্টে বন্ধ; দরকার মতো একটি একটি করে চালু করুন।
- **বটের নম্বর থেকেও কমান্ড:** যে নম্বরে বট লিংক করা, সেই নম্বর থেকে `.` দিয়ে শুরু করা কমান্ডও চলে এবং সেটি মালিক হিসেবে গণ্য হয়।

## জানা দরকার

**১. একটি সেশন = একটি জায়গা।** Termux-এ আগের বট চালু থাকলে সেটি বন্ধ করুন এবং WhatsApp → Linked devices থেকে পুরনো সেশন সরিয়ে দিন। নাহলে দুই জায়গা থেকে একই মেসেজে দুইবার রিপ্লাই যেতে পারে। একই সেশন-ফাইল দুই জায়গায় চালালে ড্যাশবোর্ড **"অন্য জায়গায় সেশন খুলেছে"** দেখিয়ে অটো-রিকানেক্ট বন্ধ করে দেয়।

**২. রিডিপ্লয়ে সামান্য ডাউনটাইম হবে।** Railway-র নিয়মে Volume যুক্ত সার্ভিসে একসাথে দুটি ডিপ্লয়মেন্ট চলে না, তাই কোড আপডেট করলে কয়েক সেকেন্ড বট বন্ধ থাকে। বট নিজে থেকে আবার সংযুক্ত হয় (সেশন Volume-এ সেভ থাকে)।

**৩. রেপ্লিকা ১টির বেশি করবেন না।** বটে একটি ফাইল-ভিত্তিক সেশন আছে; একাধিক ইনস্ট্যান্স চালালে সংঘর্ষ হবে।

**৪. খরচ।** Railway-র বিনামূল্যে ট্রায়াল সীমিত; ২৪/৭ চালাতে সাধারণত পেইড প্ল্যান লাগে। বর্তমান দাম railway.com/pricing এ দেখে নিন।

**৫. ব্যান ঝুঁকি।** Baileys অনানুষ্ঠানিক লাইব্রেরি, আর সার্ভার/ডাটাসেন্টার আইপি থেকে WhatsApp কিছুটা বেশি সন্দেহ করতে পারে। **আলাদা নতুন নম্বর ব্যবহার করুন**, মূল নম্বর নয়। নতুন লিংক করার প্রথম দিনগুলোতে বাল্ক কিক/ট্যাগ এড়ান।

**৬. ড্যাশবোর্ডের নিরাপত্তা।** যে ড্যাশবোর্ডে ঢুকতে পারে সে আপনার বট নিয়ন্ত্রণ করতে পারে। শক্ত পাসওয়ার্ড দিন, লিঙ্ক শেয়ার করবেন না। ভুল পাসওয়ার্ডে আইপি প্রতি ১৫ মিনিটে ৮ বার চেষ্টা সীমা আছে, কুকি `HttpOnly + SameSite=Strict`।

## সমস্যা সমাধান

| সমস্যা | কারণ / সমাধান |
|---|---|
| লগে "ADMIN_PASSWORD সেট করা নেই" | Variables-এ `ADMIN_PASSWORD` দিন (৮+ অক্ষর) |
| বিল্ড ফেইল (git সংক্রান্ত) | `Dockerfile` ব্যবহার হচ্ছে কিনা দেখুন — রিপোর রুটে `Dockerfile` থাকতে হবে |
| ডিপ্লয় হয় কিন্তু সাইট খোলে না | Settings → Networking এ Domain জেনারেট করেছেন কিনা দেখুন; লগে "ড্যাশবোর্ড চালু" আছে কিনা দেখুন |
| প্রতি ডিপ্লয়ে আবার QR চায় | Volume নেই বা `DATA_DIR` মাউন্ট পাথের সাথে মেলেনি |
| "কোড নেওয়া যাবে না" | অবস্থা **লগইনের অপেক্ষায়** হওয়ার পরে কোড নিন (QR দেখা গেলেই তৈরি) |
| পেয়ারিং কোড ফোন গ্রহণ করছে না | কোডের মেয়াদ কম; নতুন কোড নিন। নম্বর কান্ট্রি কোড সহ ও সঠিক কিনা দেখুন; না হলে QR ব্যবহার করুন |
| "লগআউট হয়েছে" | ফোন থেকে লিংকড ডিভাইস সরানো হয়েছে; **স্টার্ট** দিয়ে নতুন করে লিংক করুন |
| `error in handling message` লগ | নতুন লিংকের পর ডিভাইস-সিঙ্কের সময় এক-দুটি এমন লাইন স্বাভাবিক; বারবার আসলে WhatsApp লগআউট করে নতুন লিংক করুন |
